# Course Notes

## Week 1 – History
- A single writing system can be used by multiple languages.
- The medium used to store information affects how we interact with and process it.

## Week 2 – Bits and Bytes
- Bit: Short for Binary Digit, the smallest unit of digital information.
- Volatile Memory: Loses its stored data when the power is turned off.
- Non-Volatile Memory: Retains data even when the power is turned off and is used for long-term storage.

## Week 3 – Markup Languages
- Alphanumeric Characters: Letters and digits, such as `A`, `b`, `c`, and `0–9`.
- Non-Alphanumeric Characters: Characters other than letters and digits, such as `{}`, `[]`, `+`, `-`, `;`, and `)`.
- Purpose of Markup Languages: Provide instructions on how text should be displayed and interpreted.

## Week 4 – Keyboards and Editors
- IDE (Integrated Development Environment): A software application that provides tools for writing, editing, testing, and debugging code.
- Regular Expressions (RegEx): A sequence of characters used to create search patterns for finding, matching, and manipulating text.

## Week 5 – Command-Line Interface (CLI)

### Uses and Advantages of CLI
- No GUI Required: Some functionality is only available through command-line tools.
- Precise Control: Allows users to execute commands with specific instructions.
- Automation: Makes repetitive tasks easier through scripting.
- Speed: Can be faster than a graphical user interface (GUI) for certain tasks.
- Remote Access: Works efficiently over slow networks.
- Low Resource Usage:Requires fewer system resources than many GUI applications.

### Useful CLI Commands
- `ls` – Lists files and directories in the current directory.
- `pwd` – Displays the path of the current working directory.
- `cd` – Changes the current directory.
- `cat` – Displays the contents of a text file.
- `less` – Displays file contents one screen at a time.
- `cp` – Copies files or directories.
- `mv` – Moves or renames files and directories.
- `mkdir` – Creates a new directory.
- `ping` – Tests network connectivity to another host.
